# Python 크롤링 연습 가이드

이 폴더에는 `requests` + `BeautifulSoup`를 사용한 기본 크롤러 예제가 포함되어 있습니다.

## 1) 설치

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2) 예제 실행 (초간단 버전)

```bash
python crawl_quotes.py
```

- `--pages`: 최대 페이지 수 (기본 1)
- `--out`: CSV 저장 경로 (지정하지 않으면 콘솔에 미리보기만 출력)

## 3) 설정 바꾸기

- `crawl_quotes.py` 맨 위에 있는 변수로 기본 동작을 바꿀 수 있어요.
  - `START_URL`: 시작 주소
  - `PAGES`: 몇 페이지까지 볼지 (기본 1)

## 4) 연습 과제 아이디어

1. 태그별 필터 크롤링
   - 예: `https://quotes.toscrape.com/tag/love/` 페이지를 시작점으로 수집
2. 결과 저장 확장
   - CSV 외에 JSON 저장 함수 추가
3. 속도/안정성 개선
   - 요청 간 지연(sleep) 옵션 추가, 예외 처리/재시도 전략 수정
4. 일반화
   - 다른 사이트를 위한 파서 모듈을 추가하고, CLI에서 `--site` 옵션으로 선택 가능하게
5. 테스트
   - 파서 함수에 대한 단위 테스트 작성(샘플 HTML을 파일로 만들어 테스트)

## 5) 주의 사항

- 대상 사이트의 robots.txt, 이용 약관, 요청 빈도 정책을 항상 확인하세요.
- 로그인/개인정보/저작권 등 민감한 영역은 크롤링 대상에서 제외하세요.
