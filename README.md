## Sparta Coding Club 웹개발 학습 로그 (5주 코스)

이 레포지토리는 스파르타 코딩클럽 웹개발 강의의 총 5주차 분량을 하루에 1주차 단위로 학습하고, 그 결과물을 정리해 업로드하는 기록용 저장소입니다. 

### 진행 방식
- 하루 학습 목표: 1주차 분량씩 완주
- 업로드 단위: 주차별(필요 시 날짜별) 커밋
- 산출물: 실습용 HTML/CSS/JS 파일 및 간단한 실험 코드


### 주차별 학습 목표(개요)
- 1주차: HTML/CSS 기본, 레이아웃(Flex/Grid), 시맨틱 마크업
- 2주차: JavaScript 기초, DOM 조작, 이벤트 처리
- 3주차: 비동기 통신(Fetch/AJAX), JSON, 간단한 API 연동
- 4주차: 상태/스토리지(LocalStorage 등), 미니 프로젝트 1
- 5주차: 미니 프로젝트 2, 개선/리팩터링, 간단 배포(예: GitHub Pages)
